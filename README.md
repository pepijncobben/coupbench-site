# coupbench-site

Public landing page for **[coupbench.com](https://coupbench.com)**, served via GitHub Pages
from the `main` branch (root).

This repo is intentionally public and contains **only** the static placeholder page —
no benchmark data, prompts, or results. Those live in the private project repo.

- `index.html` — the page (EuroSafeAI house style: Inter, `#1C4587` blue)
- `CNAME` — custom domain for GitHub Pages (`coupbench.com`)

## Editing

Edit `index.html` and push to `main`; Pages redeploys automatically.
